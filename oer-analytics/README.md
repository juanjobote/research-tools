# OER Analytics

This module contains analytical tools for studying the dissemination, usage, and circulation of Open Educational Resources (OERs) in digital repositories.

## Description

This component builds upon the dataset generated in the *zenodo-analytics* module and focuses on the analysis of OER usage patterns. It provides scripts and workflows for examining how educational resources are accessed, distributed, and reused across multilingual and digital environments.

The analytical approach combines quantitative usage indicators with interpretative frameworks derived from Information Behaviour and knowledge circulation studies.

## Scope

The tools included in this directory are designed to:

- analyse OER usage metrics (downloads, views)  
- calculate efficiency indicators (e.g. downloads per resource, downloads per month)  
- examine multilingual dissemination patterns  
- identify high-performing resources and long-tail distributions  
- support the interpretation of knowledge circulation in open repositories  

## Analytical Focus

This module is particularly oriented towards:

- multilingual OER dissemination  
- usage-based evaluation of educational resources  
- patterns of visibility and access in digital repositories  
- relationships between content type and user interaction  

## Structure

This directory may include:

- data analysis scripts (Python or R)  
- notebooks for exploratory analysis  
- scripts for aggregation and visualisation  
- supporting documentation  

## Reproducibility

The analyses performed using this module are fully reproducible when combined with:

- the dataset generated in *zenodo-analytics*  
- the analytical scripts published with a DOI  

This ensures transparency and facilitates reuse in future research.

## Research Context

This module supports research in:

- Library and Information Science (LIS)  
- Open Educational Resources (OER)  
- multilingual knowledge circulation  
- information behaviour in digital environments  

The outputs of this module are directly linked to academic publications analysing OER dissemination and usage.
